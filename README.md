# Cypress Cloud-style dashboard

A responsive dashboard template with temporary static test data. No installation or API keys required.

## Run

Run `npm start`, then open http://localhost:3000. You can also open index.html directly.

## Included

- Project health metrics and run activity chart
- 24 sample runs with search, branch/status filters and pagination
- Run details, branch overview, analytics, flaky tests, project settings
- Responsive layout and keyboard-accessible controls

## Customize

Edit the sample `runs` data and `renderMetrics()` in app.js. Edit styles.css for colors and layout. Settings are session-only. New run displays setup instructions; it does not execute tests. All project data, profiles, notifications and usage figures are placeholders. This is an independent template inspired by Cypress Cloud, not an official Cypress product.

Design reference: https://docs.cypress.io/cloud/features/recorded-runs
